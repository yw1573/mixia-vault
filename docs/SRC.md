# KDBX4 本地密码管理器需求文档（增强完整版）

项目定位：跨平台本地密码管理器，基于 KDBX4 标准，兼容 KeePass，优先保障内存安全与数据加密安全；分为 **MVP V0.01（核心可用版）**、**V0.02（增强兼容版）**、**V0.03（长期规划）**。 核心加密基线：KDBX4，Argon2id 密钥派生，ChaCha20 内容加密。

| 版本  | 日期 | 变更说明                                                     |
| ----- | ---- | ------------------------------------------------------------ |
| V0.00 | 初始 | 原始需求草稿                                                 |
| V0.01 |      | MVP 基础功能：KDBX4 读写、分组条目 CRUD、密码生成、剪贴板、搜索、基础安全 |
| V0.02 |      | 增强兼容：KeePass 兼容、i18n 国际化、CSV 导入导出            |
| V0.03 |      | 长期迭代：高级安全、附件、自动填充、数据库健康检查等         |

## 总体目标

1. 实现遵循 KDBX4 官方规范的本地密码库，**文件可与原版 KeePass 双向互通**。
2. 强安全设计：敏感明文最小化驻留内存、可擦除敏感内存、禁止明文落盘 / 日志。
3. 提供分组、密码条目、密码生成、检索、剪贴板安全操作能力。
4. 跨平台支持：Windows / Linux /macOS。
5. 易用可靠：文件备份机制，防止数据库损坏丢失；错误提示脱敏，防止信息泄露。
6. 扩展能力：支持后续增加多语言、CSV 批量导入导出、高级安全特性。

## 范围界定

✅ 包含：KDBX4 文件创建 / 打开 / 保存 / 锁定 / 关闭；分组管理；密码条目 CRUD；密码生成；搜索；剪贴板安全操作；CSV 导入导出；国际化；基础数据库备份。 ❌ 暂不纳入 MVP：云同步、WebDAV、密钥文件、YubiKey 硬件密钥、数据库共享、审计日志（明文日志）、浏览器插件、自动填充（V0.03 考虑）。

## V0.01 MVP 核心需求（必须实现）

### KDBX4 数据库文件操作

#### 创建新数据库

- 创建全新标准 `.kdbx4` 文件。
- 用户设置**主密码**，主密码用于 Argon2id 密钥派生。
- 加密参数可预设，支持用户微调 Argon2id 参数（迭代次数、内存占用、并行度），提供安全推荐值。
- 数据库元信息：自动生成数据库 UUID、创建时间。
- 初始自动创建根分组。

#### 打开已有 `.kdbx` 文件

- 输入主密码解锁数据库。
- 错误分类与脱敏提示：
  - 主密码错误：提示 `主密码不正确`，**不返回哈希、解密堆栈、内部密钥信息，不可用于爆破**。
  - 文件格式错误：提示 `文件不是有效的KDBX4数据库`。
  - 文件损坏：提示 `数据库文件损坏，可尝试使用bak备份恢复`。
  - 文件权限不足：提示 `无文件读取权限`。
- 仅支持 KDBX4；打开 KDBX3 等旧版本提示不支持（V0.02 可考虑兼容只读）。
- 打开成功后，**所有敏感字段（密码、备注）加载到内存，不写入磁盘 / 日志**。

#### 数据库保存（安全备份机制）

> 触发时机：分组 / 条目新增、修改、删除后执行保存动作。

1. 保存前置校验：检查数据库是否处于解锁状态，锁定状态禁止保存。
2. 备份逻辑：
   - 原文件 `xxx.kdbx` → 复制为 `xxx.kdbx.bak`；
   - 若 `xxx.kdbx.bak` 已存在，**覆盖旧 bak 备份**（MVP 简化；V0.03 可做多版本备份链）；
   - 备份必须在写入新数据库之前完成；备份失败则终止保存，不覆盖原文件。
3. 将内存中加密序列化后的 KDBX4 数据写入目标文件。
4. 写入失败处理：中断保存，保留原文件与 bak，返回错误，内存数据保持不变。
5. 写入完成后，内存中明文数据保留（直到锁定 / 关闭）。

#### 数据库锁定

- 触发方式：手动锁定；可增加可选闲置自动锁定（V0.01 可选）。
- 锁定行为：**清空内存中所有明文条目、密码、备注、分组敏感描述**，覆写敏感内存区域，释放敏感内存。
- 锁定后状态：数据库文件句柄保持 / 释放可选；回到待解锁状态，无需退出程序。
- 锁定后操作限制：不能查看 / 编辑条目，仅可重新输入主密码解锁。

#### 关闭数据库

- 关闭前自动执行锁定逻辑，擦除全部明文。
- 释放数据库资源、文件句柄，清空内存缓存。
- 关闭后，所有分组、条目数据从内存清除。

### 分组（Group）管理

- 数据模型：分组 UUID、名称、父分组 UUID、备注、创建时间、修改时间、图标 ID。
- 列出分组：以树形结构展示分组名称、UUID，不包含敏感信息。
- 创建分组：指定父分组，自动生成 UUID，填写分组名称、备注。
- 重命名分组：修改分组名称，自动更新修改时间。
- 删除分组：
  - 校验：删除分组时，**连带下属所有子分组、所有条目一起删除**；
  - 增加二次确认提示，展示待删除条目 / 子分组数量；
  - 确认删除后，内存树移除对应节点，保存时同步写入 KDBX。

### 密码条目（Entry）管理

> 安全规则：条目列表**默认不展示密码明文**。

- 条目字段：UUID、标题、用户名、网址、密码、备注、创建时间、修改时间、最后访问时间、所属分组 UUID。
- 列出条目：展示标题、用户名、网址、所属分组；**密码隐藏**。支持分页（条目量大时）。
- 查看单条完整条目：展示标题、用户名、网址、密码、备注、时间信息。
- 新增条目：填写标题、用户名、网址、密码、备注；归属指定分组。
- 编辑条目：修改标题、用户名、网址、密码、备注；可迁移条目至其他分组；自动更新修改时间。
- 删除条目：二次确认，删除单条密码条目。
- 剪贴板功能：
  1. 复制密码到系统剪贴板；**不打印明文到控制台 / 日志**。
  2. 剪贴板自动清空：可配置超时秒数（默认 10 秒，范围 3~60s）；超时自动清空剪贴板。
  3. 边界：程序退出、数据库锁定时，立即清空剪贴板。
  4. 提示：复制成功后提示 “密码已复制到剪贴板，N 秒后自动清除”。

### 密码生成器

- 可配置参数：
  - 密码长度：最小 8 位，最大 128 位，默认 20 位；
  - 字符集开关：小写字母 (a-z)、大写字母 (A-Z)、数字 (0-9)、特殊符号 (`!@#$%^&*()_+-=[]{}|;:,.<>?`)；
  - 约束：保证至少选择一类字符；可增加选项：避免连续重复字符、避免易混淆字符（0/O、1/l）。
- 密码随机源：使用系统密码学安全随机数（CSPRNG），禁止伪随机。
- 生成结果：可预览；可直接填入新建 / 编辑条目的密码字段；**生成的明文不写入日志**。

### 条目搜索

- 检索范围：标题、用户名、网址；**不检索密码明文**（安全约束）。
- 匹配方式：不区分大小写，简单关键字包含匹配。
- 返回结果：条目列表模式（隐藏密码），展示匹配条目所属分组。
- 支持清空搜索结果。

### V0.01 硬性安全要求

1. 数据库锁定：一键擦除内存全部明文，程序不退出。
2. 控制台 / 日志：**严禁输出任何密码明文**；错误日志脱敏，禁止泄露密钥、哈希、内部解密状态。
3. 磁盘规则：任何场景下密码明文**不写入磁盘、不写入日志文件**；仅加密后的 KDBX4 容器落盘。
4. 内存安全：敏感数据使用可覆写字节数组；使用完成后覆盖清零；尽量规避不可变字符串存储明文，减少内存 dump 泄露风险。
5. 主密码输入：输入时禁止回显明文。
6. 最小明文原则：不需要查看时，尽量不在内存长时间保留密码明文。

## V0.02 增强迭代需求

### KeePass 文件兼容性

1. 打开原版 KeePass 创建的标准 KDBX4 文件，正常读取分组、条目。
2. 保存生成的 `.kdbx` 文件，可被原版 KeePass2.x 正常打开、读取。
3. 兼容 KDBX4 标准扩展字段（自定义字符串属性）；MVP 暂不支持附件（附件放在 V0.03）。
4. 校验：保存后文件结构、元数据、加密字段符合 KDBX4 规范。
5. 边界：非标准 / 损坏的第三方 kdbx，给出友好提示，不崩溃。

### 国际化 i18n

1. UI/CLI 提示文本支持多语言；内置语言包：简体中文、英文。
2. 语言包独立 JSON/YAML 文件，不硬编码文本；可新增翻译文件。
3. 支持运行时切换语言，无需重启程序。
4. 字段内容（条目标题、备注等）本身支持 UTF-8 多国文字存储。

### CSV 导入 / 导出

> 字段映射：标题，用户名，网址，密码，备注，分组

1. CSV 导出
   - 可选：是否导出密码明文（默认不导出明文）。
   - 编码：UTF-8，带 BOM 可选，兼容 Excel 打开。
   - 导出前校验：数据库必须处于解锁状态。
2. CSV 导入
   - 读取 CSV，自动字段映射；支持手动调整列映射。
   - 导入校验：空标题过滤、字段长度限制；导入预览，展示待导入条目数量。
   - 冲突策略：遇到重复标题条目，可选：跳过、覆盖、重命名。
   - 批量导入到指定父分组。
   - 导入完成后统计：成功条目、跳过条目、失败条目。
3. 安全提示：CSV 是明文文件，导入导出时弹窗提示用户妥善保管 CSV 文件。

## 非功能需求

### 安全性（最高优先级）

1. 加密标准：严格遵循 KDBX4 规范；Argon2id + ChaCha20。
2. 随机数：所有密码生成、UUID 生成使用密码学安全随机源。
3. 内存防护：敏感内存覆写清零；尽量减少明文在内存驻留时间。
4. 错误脱敏：所有错误信息不能作为信息泄露渠道，不能辅助暴力破解。
5. 防崩溃：解析异常文件不能导致程序 panic，做好边界校验。

### 性能

1. 本地文件，不依赖网络；所有操作本地完成。
2. 数百条条目：打开、搜索、保存响应无感。
3. 上千条目：搜索仍保持流畅；列表支持分页加载。

### 可移植性

1. 跨平台：Windows / Linux /macOS。
2. 单一本地文件存储，无额外数据库。
3. 不依赖外部服务，离线可用。

### 可维护性

1. 模块分层：底层 KDBX 编解码层、业务模型层、交互层，解耦。
2. 单元测试：KDBX 读写测试、加解密测试、内存擦除测试、密码生成测试。
3. 安全测试：内存 dump 测试、剪贴板泄露测试。

## 风险与约束

| 风险                           | 应对措施                                                     |
| ------------------------------ | ------------------------------------------------------------ |
| KDBX 编解码 bug 导致数据库损坏 | 保存前自动 bak 备份；数据库健康校验；大量修改前提示用户备份  |
| 内存明文残留                   | 敏感数据使用 byte 数组，锁定 / 关闭时主动覆写清零；避免使用不可变字符串存放密码 |
| 剪贴板泄露                     | 超时自动清空；锁定 / 关闭立刻清空剪贴板；明确安全提示        |
| CSV 明文导出泄露               | 默认不导出密码；导出时安全告警；提醒用户 CSV 文件风险        |
| 主密码丢失                     | **无法恢复数据库！** 界面明确提示：主密码遗忘，加密库无法解密，无后门、无密码找回机制 |

## 模块拆分建议

1. **Crypto & KDBX 底层模块**：Argon2id 密钥派生、ChaCha20、KDBX4 序列化 / 反序列化、文件备份。
2. **安全内存模块**：SecureBytes（可覆写敏感字节）、内存擦除、剪贴板管理。
3. **数据模型模块**：Group、Entry 模型，CRUD、树结构管理。
4. **业务逻辑模块**：数据库锁定 / 解锁、搜索、密码生成。
5. **导入导出模块**：CSV 导入导出（V0.02）。
6. **i18n 国际化模块**（V0.02）。
7. **交互层**：CLI / TUI / UI。
